# Sistema de Gestión Clínica Dental (`BDCitasDentales`)

Sistema web académico desarrollado para la gestión operativa de una clínica odontológica, con autenticación de usuarios, administración de información clínica y conexión a base de datos relacional en SQL Server.

## Tecnologías utilizadas
* **Lenguaje y Framework:** C# (.NET Framework)
* **Frontend y Backend Web:** ASP.NET Web Forms, HTML5, CSS3, Bootstrap
* **Base de datos:** Microsoft SQL Server

## Estructura del repositorio
* `ClinicaWeb/`: Código fuente del portal web (formularios `.aspx`, lógica en C#, páginas maestras, estilos CSS y configuración).
* `database/`: Archivos de base de datos de SQL Server (`BDCitasDentales.MDF` y `BDCitasDentales_log.LDF`).
* `Clinica_Dental.slnx`: Archivo de solución de Visual Studio.
